# 🎵 SoundSwipe

TuneSwipe is a sleek music discovery app built with React, TypeScript, and Tailwind CSS. It blends a Tinder-like swipe flow with a record-collector vibe to help users discover new songs, save favorites, and build a personal library of tracks they actually love.

## ✨ What makes it special

- 🎧 Swipe-based music discovery
- ❤️ Love tracks you want to keep
- ⭐ Save tracks for later
- 🌍 Browse by country and genre
- 📚 Keep a personalized library
- 🎶 Instant audio previews
- 💎 Premium dark-and-warm vinyl-inspired design

## 🧩 Core idea

TuneSwipe turns music discovery into a quick, playful experience:

1. Choose a genre
2. Select a country/music origin
3. Swipe through a curated track queue
4. Love, save, or skip each track
5. Keep the songs that match your taste in your library

It feels like combining a music app, a recommendation engine, and a stylish swipe interface into one product.

## 🛠️ Tech stack

- React + TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- iTunes Search API
- shadcn/ui inspired component patterns

## 🚀 Getting started

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm run dev
```

### Production build

```bash
npm run build
```

### Run tests

```bash
npm run test
```

## 📁 Project flow

- Discover page: swipe through tracks
- Library page: review saved songs and genre filters
- Track detail modal: preview, open links, and manage actions
- Local storage: remembers swipe history and library state

## 🎨 Design direction

TuneSwipe follows a premium aesthetic inspired by:
